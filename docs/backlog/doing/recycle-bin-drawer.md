# 回收站交互调整：抽屉式半栏覆盖 + 清空图标放大

## 背景与现象

recycle-bin（回收站，方案 A）合入后用户实测反馈两点：

1. **整栏切换不符合预期**：点击「回收站 (N)」入口目前把整个侧栏会话列表替换成回收站视图（‹ 返回 + 标题 + 清空 + 恢复全部 + 分组列表）。用户希望回收站是**抽屉式面板——从侧栏拉起来占据半个侧栏**（不全部占据），主列表仍可见/可交互，回收站面板叠加在其上。
2. **清空回收站图标太小**：回收站视图头部的清空图标按钮（垃圾桶，截图）约 20px 见方、图标更小，点击目标小且视觉不均衡（旁边「恢复全部」是文本按钮）。需放大到与文本按钮相称的可点击尺寸。

## 需求（用户原话）

1. 「点击回收站我不希望进入一个新的侧栏，我希望回收站这个栏拉起来占据半个侧栏，而不是全部占据」
2. 清空回收站图标太小（截图见条目来源）

## 建议方案（实现时细化，指明方向）

1. **抽屉面板**：入口行点击 → 侧栏下半部（约 50% 高）从底部滑出回收站面板；主列表上半部保留可见。交互要素：
   - 面板可收起（点击面板外区域/‹ 按钮/再次点入口行？——以常见抽屉交互为准，实现时定并保持可发现性）
   - 面板内保留现有全部功能：按原 workspace 分组、组头计数+折叠、行菜单（移入已在主列表；面板内是恢复/归档）、恢复全部、清空（图标按钮）、置顶保护在面板内同样生效
   - 半高面板下主列表仍可滚动/选中（与抽屉遮罩的关系实现时定：无遮罩直接叠 + 点击外部收起，或轻量遮罩）
   - 计数徽标、空态引导保留
2. **清空图标放大**：图标按钮从 ~20px 放大到 ≥32px 点击区（或用显式图标尺寸），与「恢复全部」文本按钮视觉均衡；保持悬停提示。
3. 抽屉面板高度是否可拖（可选，做不做实现时定；优先固定半高、保持简单）。

## 涉及代码位置

- `src/ui/sessionsWebview.ts`：回收站视图渲染（renderRecycleBin 等改为抽屉容器）+ 入口点击行为 + 清空图标样式
- `src/ui/sessionsView.ts`（样式常量 SESSIONS_STYLE 所在）：抽屉布局样式、遮罩/过渡、图标尺寸
- `src/ui/sessionsStore.ts`：状态不变（本地集合，复用）
- `test/ui/scenarios.js` 或沙盒 E2E：若有 harness 场景则更新期望（回收站相关目前是临时 Playwright E2E，开发时补持久断言或以报告注明）
