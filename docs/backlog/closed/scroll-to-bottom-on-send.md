# 发送消息后自动滚动到最新

## 背景与现象

在聊天对话框里发送一条消息后，消息列表不一定会滚到最底部。如果发送前用户滚动看过历史消息，跟随态已被解除，新消息（以及随后的流式回复）在视口外增长，用户要自己手动滚回去才能看到。

期望行为：发送消息是明确的"我要看最新内容"信号，发送后应立即把消息列表滚到最底部并重新进入跟随态，后续流式输出继续贴底。

## 现状

已有贴底跟随逻辑：用户滚动到距底超过阈值时解除跟随，避免流式输出把视图钉住（这是需要的）。但发送消息时没有主动复位跟随态的钩子。

## 建议方案

在发送消息的路径上（webview 提交消息后），无条件把消息容器滚到底（`scrollTop = scrollHeight`），并把跟随态置为跟随。复用现有的 `distanceFromBottom` / `isNearBottom` 判定，不要绕过跟随机制直接操作。

注意：发送动作应视为"用户意图"之外的程序滚动，不要触发现有的用户滚动判定把跟随态又解掉。

## 涉及代码位置

- `src/pure/scrollFollow.ts` — 贴底跟随的纯函数判定
- `src/ui/chat/webview.ts` — 聊天 webview，发送消息与滚动行为都在这里
